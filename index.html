Core projectEquinix

Network intelligence and optical performance monitoring

Network teams had to review optical performance data by hand. I built an automated workflow that extracts the data every hour, checks it against threshold and deviation rules, and delivers exceptions to the Global Network Operations Center.

Python · SQL · PostgreSQL · Prefect · Power BI
92current transmission devices
1,240current ports
63Ciena 6500 devices (separate scope)
3Power BI dashboards
  • Hourly extraction; three scheduled notification cycles a day covering day and night shifts.
  • Tracks new, persistent and recovered out-of-range conditions, not just a list of breaches.
  • Moved from file-based processing to direct PostgreSQL processing, with Prefect scheduling and automated recovery.
  • Fixed an extraction pattern that was exhausting temporary storage.

Public case studies use synthetic data. Thresholds, device names and topology are confidential.

In progress Extending the same approach to IP networks (about 60 devices, 122 interfaces).

Real-time electrical grid streaming pipeline

A synthetic smart-meter stream ingested every 30 seconds on Databricks and processed through a medallion architecture with Lakeflow Declarative Pipelines. Five Gold tables power an AI/BI dashboard and a Genie bot for grid health, transformer performance and energy cost.
